Practice your Handwriting

Printable A4 practice sheets with guide lines and dotted letters to trace. Pick a sheet type and a font, then print.

Loads from Google, sends your IP address to Google

How it works
  1. Pick a sheet type — the ruling that fits what you practise.
  2. Pick a font — the letters are drawn in it: one solid model letter, then dotted copies to trace.
  3. Print — ⌘/Ctrl + P, paper A4, margins None. Each preview sheet is one printed page.

The controls

Sheet type
The guide lines on the page. Line spacing is fixed per type so the guides stay true to scale.
Paper
A4 portrait or landscape. Landscape rows are longer but fewer fit per page, so the alphabet continues on more sheets. When printing, the page orientation follows this choice.
Font
Fonts from the fonts/ folder next to this page. Works offline. The hosted page ships only Playwrite CA; to use your own fonts, run the page locally (see below) or use the online Google Font field.
Online Google Font
Start typing to pick from popular handwriting fonts on Google Fonts, or type any other Google Fonts name exactly (e.g. Pinyon Script). Needs internet; choosing a font from the list again switches back. Privacy: the font is loaded from Google's servers, which sends your IP address to Google. Nothing is requested until you enter a name.
Letters
Lowercase, uppercase, or both as letter pairs (Aa, Bb, Cc …) — pairs need more room, so fewer fit per row. Long alphabets continue on extra sheets.
Only these letters
Type the letters you want to practise (e.g. aeoc); case is ignored and the Letters choice decides lowercase, uppercase or pairs. Leave empty for the whole alphabet. Only a–z are supported.
Lines per letter
How many rows each letter gets (1–10), grouped: with 3, a is practised on three rows, then e on three rows. Extra rows continue on more sheets.
Letter size
Set automatically so the font's x-height matches the guides whenever you change sheet type or font. Drag to fine-tune. The maximum is limited so the tallest letter reaches at most 25% past the room above the baseline (the ascender line on Copperplate), so fonts with very tall ascenders get a smaller size.
Slant angle
Angle of the slant lines, 45–90° (55° by default). Only shown for sheet types with slant lines. It changes the guides, not the letters: the letters keep the slant of the font.
Repeats / row
How many dotted letters follow each model letter (3–14).

Sheet types

Copperplate guides
Ascender, x-height, baseline and descender lines in 3:2:3 proportion, with dotted slant lines (angle adjustable, 55° by default). Letters start in the middle of a slant space.
Handwriting lines
Top line, dashed x-height line and baseline — classic school ruling.
Slant bands
A 5 mm x-height band with dotted slants (angle adjustable); letters start in the middle of a slant space.
Slant grid
20 mm cells with sub-lines and a diagonal; one letter per cell.
Dot grid / Square grid
Neutral 5 mm grids for free practice.

Adding your own fonts (local copy only)

Download the project and open index.html from your computer. Drop .otf, .ttf, .woff or .woff2 files into the fonts/ folder, then run scripts/update-fonts-manifest.sh (macOS/Linux) or double-click scripts\update-fonts-manifest.cmd (Windows) and reload this page.
